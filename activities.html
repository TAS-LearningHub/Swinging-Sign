Applied Learning Activities

Practise the idea, then explain it.

Fifteen varied activities connect directly to the named course sections. They are useful in lessons, for revision, for fast finishers and for source-grounded relief work.

Formative practice only: activity responses save in this browser. They do not replace each section's higher-order response or formal submission.

Module 1 · Evidence detective

Evidence sort

Observation, inference, purpose and product analysis

What to do

  • Prepare: One teacher-approved product photograph, Four sticky notes or a digital note space
  • Write two observation notes using only visible evidence.
  • Write one interpretation note that connects a feature to a likely user need.
  • Write one confirmation question about an unknown practical detail.
  • Swap with a partner and check whether every claim is labelled accurately.

Evidence to keep: A four-note evidence set plus a revised product-analysis sentence.

Printable / low-tech: complete the same task on paper, then photograph or summarise the result in My folio.

Boundary: Use only teacher-approved images. The activity does not authorise measurement, dismantling or practical testing.

Module 1 · Pathway brief studio

Criteria ranking

Briefs, criteria, constraints and trade-offs

What to do

  • Prepare: Three project reference images, Brief-and-boundaries template
  • Choose the pathway your teacher has nominated, or use one as a planning scenario.
  • Write a two-sentence brief naming user, need and intended response.
  • Add three testable criteria and a separate list of confirmation questions.
  • Circle the highest-priority criterion and explain one likely trade-off.

Evidence to keep: A source-safe brief with labelled criteria, confirmation questions and a trade-off explanation.

Printable / low-tech: complete the same task on paper, then photograph or summarise the result in My folio.

Boundary: The activity compares design thinking only. Your teacher supplies the approved project plan and practical constraints.

Module 1 · Decision gate: ready, responsible, recorded

Risk-and-resource scan

Readiness checks and life-cycle reasoning

What to do

  • Prepare: Teacher-provided planning scenarios, Three-column decision sheet
  • For each scenario, identify the confirmed information, the missing information and the next responsible action.
  • Add one possible life-cycle effect to each scenario.
  • Choose one scenario and improve the proposed decision.
  • Record the evidence you would need before saying the improvement worked.

Evidence to keep: A completed decision sheet and one justified revised decision.

Printable / low-tech: complete the same task on paper, then photograph or summarise the result in My folio.

Boundary: This is a paper or digital planning activity. It does not authorise any practical action or replace local safety instruction.

Module 2 · Format triage

Visual comparison

Vector, bitmap, scaling and tracing

What to do

  • Prepare: Teacher-provided image samples, Format decision cards
  • Sort the samples into likely vector, likely bitmap and needs more evidence.
  • For each choice, name one visible clue and one suitable use.
  • Select one bitmap sample and predict two issues an automatic trace might create.
  • Write a source-permission question before proposing any reuse.

Evidence to keep: A completed format sort with four written justifications and one tracing-risk note.

Printable / low-tech: complete the same task on paper, then photograph or summarise the result in My folio.

Boundary: Use only teacher-approved files. No file is considered production-ready until the teacher reviews it.

Module 2 · Onshape constraint clinic

Constraint check

Sketch planes, dimensions, constraints, features and reviewable versions

What to do

  • Prepare: Teacher-provided Onshape practice document or annotated stills, Constraint-clinic observation sheet
  • Identify the sketch plane and one item of geometry that can still move.
  • Predict a purposeful dimension or geometric constraint and explain the intended relationship before applying it.
  • Check the sketch feedback, then trace how the sketch connects to the basic feature.
  • Save or describe a new version and write two points for teacher review.

Evidence to keep: A labelled sketch-state check, two constraint or dimension justifications, a sketch-to-feature explanation and a version note.

Printable / low-tech: complete the same task on paper, then photograph or summarise the result in My folio.

Boundary: Use only the teacher-supplied Onshape document, dimensions, class folder and sharing instructions. Do not export or send a file to equipment.

Module 2 · Legibility lab

Peer-review protocol

Hierarchy, annotation, peer review and controlled revision

What to do

  • Prepare: Two teacher-provided sign concepts, Brief viewing cards, Feedback slips
  • Run the same brief-viewing check on both concepts and record what you noticed first, second and third.
  • Identify one legibility strength and one issue using visible evidence.
  • Write a notice-connect-suggest comment for one designer.
  • Propose one controlled revision and a feature-reason-effect annotation.

Evidence to keep: A reading-order record, one criteria-based feedback slip and one annotated revision proposal.

Printable / low-tech: complete the same task on paper, then photograph or summarise the result in My folio.

Boundary: This activity reviews communication only. Any practical implication of a design change requires teacher confirmation.

Module 3 · Build a property decision matrix

Decision matrix

Rehearse evidence-based selection before the higher-order response.

What to do

  • Choose one project pathway. Create a matrix with three confirmed needs, the properties that should be investigated, evidence available for each teacher-approved option and one unknown that must be checked. Finish with a two-sentence provisional recommendation.

Evidence to keep: Completed matrix and provisional recommendation.

Printable / low-tech: complete the same task on paper, then photograph or summarise the result in My folio.

Boundary: Do not add dimensions, grades, thicknesses, loads or processes unless they appear in the approved local project information.

Module 3 · Paper nesting challenge

Nesting challenge

Practise layout and resource-efficiency reasoning without using workshop equipment.

What to do

  • Arrange a teacher-provided set of paper shapes on a printed grid in two different ways. Record coverage, circle any connected useful offcut area and annotate one communication advantage and one limitation for each arrangement.

Evidence to keep: Two annotated paper layouts and a short comparison.

Printable / low-tech: complete the same task on paper, then photograph or summarise the result in My folio.

Boundary: This is a paper planning model. It does not establish project spacing, edge allowances or machine settings.

Module 3 · Audit a fictional approval pack

Approval-gate case

Practise readiness checking without exporting or operating a production file.

What to do

  • Examine teacher-provided fictional cards for an Onshape drawing preview, version record, criteria check, layout and mounting proposal. Sort them into present, unclear and missing, then write the three questions that should be resolved at the hold point.

Evidence to keep: Completed Onshape drawing-and-approval audit and three review questions.

Printable / low-tech: complete the same task on paper, then photograph or summarise the result in My folio.

Boundary: This activity does not certify a file or authorise any practical process.

Module 4 · Build a production-control board

Sequence cards

Make sequence, roles and hold points visible before practical work.

What to do

  • Arrange broad stage cards for a fictional product, draw dependency arrows, place at least three hold-point markers and label who prepares evidence, who checks and who authorises. Add one change scenario and show where the sequence pauses.

Evidence to keep: Annotated control board and one paragraph explaining the most important hold point.

Printable / low-tech: complete the same task on paper, then photograph or summarise the result in My folio.

Boundary: Use broad planning language only; do not add machine settings, operating steps or unconfirmed safety rules.

Module 4 · Turn opinions into quality evidence

Quality classification

Practise precise inspection language before recording real project evidence.

What to do

  • Rewrite six vague comments about fictional sample images into notes that state observed condition, location, affected criterion and decision required. Pair-check each note against the approved reference description.

Evidence to keep: Six rewritten inspection notes and one peer revision.

Printable / low-tech: complete the same task on paper, then photograph or summarise the result in My folio.

Boundary: Use provided images only. Do not touch or test actual edges as part of this activity.

Module 4 · Edit a process-evidence story

Offcut triage

Select evidence for decision-making rather than collecting images as decoration.

What to do

  • From a teacher-provided fictional set of twelve privacy-safe images and notes, select five that best connect plan, approval, result, quality and offcut decision. Write a precise caption for each and one future improvement proposal.

Evidence to keep: Five-item evidence sequence with captions and one improvement proposal.

Printable / low-tech: complete the same task on paper, then photograph or summarise the result in My folio.

Boundary: Do not photograph workshop people, controls or actual material unless your teacher authorises it.

Finish evidence comparison

Practise compatibility and quality reasoning without using coating products.

What to do

  • Review a fictional set of substrate, environment, preparation-purpose, primer and topcoat cards. Identify two supported connections, two unsupported assumptions and three questions that need product or teacher confirmation. Finish with one criteria-based inspection statement.

Evidence to keep: Annotated system map and inspection statement.

Printable / low-tech: complete the same task on paper, then photograph or summarise the result in My folio.

Module 5 · Reason with a cardboard balance model

Systems map

Explore mass distribution and connection geometry without loading or installing an actual project.

What to do

  • Use a teacher-provided cardboard mobile diagram or model. Predict its resting orientation, compare it with the supplied result, trace the conceptual load path and explain one change that could alter balance. List the project facts that cannot be transferred from the model.

Evidence to keep: Annotated model diagram, prediction and transfer-limit list.

Printable / low-tech: complete the same task on paper, then photograph or summarise the result in My folio.

Boundary: This learning model does not authorise any actual hanging, loading, installation or use test.

Module 5 · Feedback triage and improvement pitch

Feedback-to-improvement ladder

Practise deciding which feedback should influence the next iteration.

What to do

  • Sort a fictional set of feedback into criterion-linked, preference-only and needs-clarification groups. Select the strongest two comments, connect each to evidence, then give a sixty-second improvement pitch naming one change, predicted benefit and future check.

Evidence to keep: Feedback triage table and written improvement pitch.

Printable / low-tech: complete the same task on paper, then photograph or summarise the result in My folio.

Boundary: This is formative learning evidence. It does not create a formal mark or replace teacher assessment instructions.
