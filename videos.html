Module 1

Read the product and user

Streaming state: No external clip is required.

Why no clip: The required learning is specific to the authorised project brief and photograph; generic product-analysis videos would add little and could encourage unsupported assumptions.

Learning purpose: Distinguish observation from inference while identifying purpose, audience and context.

Complete no-stream pathway

  1. Study a supplied product image for thirty seconds without writing.
  2. Record three details you can see and begin each with ‘I observe…’.
  3. Record two possible explanations and begin each with ‘This might mean…’.
  4. Write one question that must be answered before the image could guide practical work.

Module 1

Criteria, constraints and project pathways

Streaming state: No external clip is required.

Why no clip: Only the course source map can represent these three pathways and their unresolved local details accurately.

Learning purpose: Classify design statements and identify unsupported specifications.

Complete no-stream pathway

Module 2

Vector and bitmap

Streaming state: No external clip is required.

Why no clip: The selected Onshape tutorials do not directly teach raster-versus-vector structure; the section's comparison visual and no-stream task provide the exact learning instead.

Learning purpose: Infer whether an image is vector or bitmap by examining structure and editing behaviour.

Complete no-stream pathway

  1. Inspect teacher-provided close-ups of two digital images at several zoom levels.
  2. Circle evidence of pixels on one image and points or paths on the other.
  3. Match each image to a suitable purpose: photograph, clean symbol or editable lettering.
  4. Explain one reason the file label alone may be misleading.

Module 2

Onshape sketches and features

Streaming state: One purpose-matched clip is optional. The no-stream pathway remains complete.

Optional verified clip: Basic Features in Onshape · Onshape · use 0:00–8:15.

Watch for: How do features turn a 2D sketch into or modify a 3D part, and why does the feature list matter when the design changes?

Open on YouTube

Learning purpose: Connect sketch planes, dimensions, constraints and features in a controlled Onshape workflow.

Complete no-stream pathway

  1. Inspect the supplied stills and identify the sketch plane, unconstrained movement and visible geometry relationships.
  2. Predict which purposeful dimension or constraint would remove each remaining movement, and name one combination that could conflict or duplicate control.
  3. Trace the sketch-to-feature relationship and explain what would update if the upstream sketch changed.
  4. Write a short version note and two questions for teacher review.

Module 2

Legibility, annotation and peer review

Streaming state: No external clip is required.

Why no clip: Available clips were either generic typography tutorials or software demonstrations and did not teach the combined sign-legibility, annotation and peer-review decision required here.

Learning purpose: Test visual hierarchy and improve the explanation of design decisions.

Complete no-stream pathway

  1. View a teacher-provided concept briefly, then look away and record what you noticed first, second and third.

  3. Rewrite one label as a feature-reason-effect annotation.
  4. Give one notice-connect-suggest comment linked to a criterion.

Module 3

Material properties and selection

Streaming state: No external clip is required.

Why no clip: The correct selection depends on local stock, grade, thickness, finish, cost and project plan, none of which a generic materials clip can establish.

Learning purpose: Covers the same property, trade-off and justification ideas as the section's visual explanation without requiring video or audio.

Complete no-stream pathway

  1. Read four short product needs: readable display, low handling mass, durable surface and efficient use of stock.
  2. Match each need to the property you would investigate, then explain why the match is relevant.
  3. Read the model comparison and identify the evidence, trade-off and conditional decision.

Module 3

Measurement, layout and resource efficiency

Streaming state: No external clip is required.

Why no clip: A useful clip would need the approved sheet, stock, kerf, margin and project dimensions; these local production facts are not confirmed.

Learning purpose: Provides the same layout comparison, simple yield calculation and approval boundary without video.

Complete no-stream pathway

Module 4

Edges, finishing and quality

Streaming state: No external clip is required.

Why no clip: The safe method depends on the actual material, edge condition, available tools and local procedure; generic demonstrations are not a responsible substitute.

Learning purpose: Provides the same criteria comparison and inspection reasoning while deliberately excluding operational edge-finishing footage.

Complete no-stream pathway
